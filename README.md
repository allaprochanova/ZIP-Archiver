Репозиторий ZIP Archiver
Описание
ZIP Archiver – это набор консольных утилит на 8 языках программирования для работы с ZIP-архивами. Программа позволяет создавать, распаковывать, просматривать, модифицировать и комментировать ZIP-архивы, используя богатый набор функций, включая настройку уровня сжатия, добавление/удаление файлов и работу с паролями (где поддерживается).

Проект создан как тестовый репозиторий для демонстрации реализации одной задачи на разных языках с использованием как встроенных, так и внешних библиотек, с акцентом на удобство использования и расширяемость.

Возможности
Создание архива – рекурсивное добавление файлов и папок.

Распаковка архива – извлечение всех файлов с сохранением структуры.

Просмотр содержимого – вывод списка файлов с размерами и датами.

Добавление файлов – добавление новых файлов в существующий архив.

Удаление файлов – удаление файлов из архива по имени.

Уровень сжатия – выбор от 0 (без сжатия) до 9 (максимальное).

Комментарий – добавление комментария к архиву (опционально).

Парольная защита (для языков с поддержкой) – шифрование архива паролем.

Кроссплатформенность – работает на Windows, macOS, Linux.

Установка и запуск
Для работы программ требуются соответствующие среды выполнения и, в некоторых случаях, установка внешних зависимостей.

Язык	Зависимости	Команда запуска
Python	Python 3.8+ (модуль zipfile встроен)	python zip.py [команда] [аргументы]
JavaScript	Node.js 14+ и npm install adm-zip	node zip.js [команда] [аргументы]
TypeScript	Node.js + ts-node, npm install adm-zip @types/adm-zip	ts-node zip.ts [команда] [аргументы]
Go	Go 1.18+ (стандартная библиотека)	go run zip.go [команда] [аргументы]
Java	JDK 11+ (стандартная библиотека)	javac ZipArchiver.java && java ZipArchiver [команда] [аргументы]
C#	.NET SDK 6.0+ (стандартная библиотека)	dotnet run или csc
PHP	PHP 8.0+ и расширение zip (обычно включено)	php zip.php [команда] [аргументы]
Ruby	Ruby 2.7+ и gem install rubyzip	ruby zip.rb [команда] [аргументы]
Использование
Все реализации поддерживают единый интерфейс командной строки:

text
zip <команда> [опции]
Команды
Команда	Описание
create	Создать новый архив. Требует --archive и --files (список файлов).
extract	Распаковать архив. Требует --archive и опционально --output.
list	Показать содержимое архива. Требует --archive.
add	Добавить файлы в существующий архив. Требует --archive и --files.
remove	Удалить файлы из архива. Требует --archive и --files.
comment	Добавить или изменить комментарий. Требует --archive и --text.
Общие опции
Опция	Описание
-a, --archive	Имя ZIP-архива.
-f, --files	Список файлов/папок для добавления (разделённые пробелами).
-o, --output	Папка для распаковки (по умолчанию текущая).
-l, --level	Уровень сжатия (0-9, по умолчанию 6).
-p, --password	Пароль для шифрования (если поддерживается).
-t, --text	Текст комментария.
-h, --help	Показать справку.
Примеры
bash
# Создать архив с двумя файлами
python zip.py create -a archive.zip -f file1.txt file2.txt -l 9

# Просмотреть содержимое
python zip.py list -a archive.zip

# Добавить файл
python zip.py add -a archive.zip -f newfile.txt

# Удалить файл
python zip.py remove -a archive.zip -f file1.txt

# Распаковать в папку out
python zip.py extract -a archive.zip -o out

# Добавить комментарий
python zip.py comment -a archive.zip -t "My backup archive"
Особенности реализаций
Python – использует встроенный модуль zipfile, поддерживает комментарии, уровни сжатия, но не шифрование (только чтение).

JavaScript – использует библиотеку adm-zip для полной поддержки, включая удаление файлов.

TypeScript – аналогично JS, с типизацией.

Go – использует стандартный пакет archive/zip, поддерживает комментарии, но требует ручного управления потоком.

Java – использует java.util.zip и ZipFile/ZipOutputStream, поддерживает всё, кроме удаления (требует пересоздания архива).

C# – использует System.IO.Compression.ZipArchive, поддерживает все операции.

PHP – использует класс ZipArchive, поддерживает все операции.

Ruby – использует gem rubyzip, поддерживает все операции.
